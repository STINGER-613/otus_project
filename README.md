Данный репозиторий содержит в себе файлы по настройке серверов 

Его основная задача:
- настроить вебсервер с балансировкой нагрузки
- настроить MySQL репликацию (master-slave)
- создавать бэкап БД со slave сервера (потаблично с указанием позиции бинлога)
- настроить систему мониторинга
- на основании скриптов, конфигов, cron файлов и бэкапов в максимально короткие сроки настроить новый сервер "с нуля"
- на чистом сервере за короткий промежуток времени получить полностью настроенную рабочую систему

При запуске скрипта BASH будет выполнена усткановка необходимого ПО и зависимостей
По окончанию настройки, скрипт выведет меню с выбором
В зависимости от того, какой сервер перед вами, нужно будет выбрать соответствующий пункт

Для настроки сервера с 0 нужно будет дополнить информацию (ведется разработка)
